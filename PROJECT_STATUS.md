# AgentHQ implementation status

## Completed in this starter
- React + TypeScript + Vite app shell
- Interactive React Three Fiber scene
- Procedural office floor, walls, partitions, desks, chairs, meeting table and plants
- Six preview employee figures with selectable name tags
- Employee side panel and summary metrics
- FastAPI health endpoint, agent preview endpoint and Ollama reachability check
- Local WebSocket endpoint placeholder for later event streaming
- Loopback-only backend binding in the provided PowerShell runner

## Not implemented yet (intentionally)
- Real AI reasoning / model chat from the dashboard
- Durable employee profiles and SQLite task records
- Task creation, assignment, execution and completion
- File tools / terminal tools / sandbox / approvals
- Autonomous scheduling and agent-to-agent delegation
- Rigged human character models and production animations

The dashboard labels its current employees as preview data. Do not treat the sample activity labels as proof that AI tasks have run.
